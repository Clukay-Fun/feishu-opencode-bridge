# Knowledge Base

Bridge 内置法律知识库能力，支持查询和入库。

## 查询

用户问"知识库里有没有""查一下知识库""根据知识库回答"时，应引导用户使用 Bridge 知识库入口：

- `/kb search <问题>` — 搜索知识库
- `/kb ingest` — 入库模式

或直接发送自然语言，Bridge 会识别并路由到知识库。

## 入库

用户上传材料并说"收入知识库"时，走知识库入库流程。Bridge 会弹出确认卡片，用户确认后才入库。

## 回答规则

- **不要说"没有知识库能力"**。Bridge 支持完整的法律知识库。
- **不要把"普通文件总结"误判成知识库入库**。只有用户明确说"入库""加入知识库"时才走知识库流程。
- **不要在不知道知识库内容时编造答案**。如果需要查询，引导用户使用 `/kb search`。
- **知识库查询有 IO 成本**，不要每轮都自动查询。只在用户明确要求时查询。

## 暂不支持

- 自动检索并注入 OpenCode（v2）
- Bridge_kb_query / Bridge_kb_search MCP 工具（v2）
